# Catch and Edit Text (Dual)

Catches text from two separate inputs making them editable

This node acts as a receiver and editor for text sent from two sources.

action widget:

  - use_input: pass the input text as it without modification.
  - use_edit_mute_input: pass the edited text in the widget and mute the source node of the input(s).

Based on the original CatchEditTextNode by ImagineerNL

https://github.com/ImagineerNL/ComfyUI-IMGNR-Utils

If you just need one text input then I recommend using his original node.
